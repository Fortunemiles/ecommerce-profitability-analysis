# E-Commerce Profitability Analysis — Key Findings

## 1. Executive Summary

This analysis evaluates e-commerce sales performance, profitability, product performance, retailer performance, geographic markets, order methods, sales trends, and discounting patterns.

The analysis was conducted using MySQL on sales data covering the period from January 2015 to July 2018.

### Overall Performance

| KPI | Value |
|---|---:|
| Total Sales Records | 149,257 |
| Total Units Sold | 19,795,947 |
| Total Revenue | 1.25B |
| Total Cost | 723.78M |
| Total Profit | 527.73M |
| Profit Margin | 42.17% |
| Total Discount Value | 66.47M |
| Overall Discount Rate | 5.04% |

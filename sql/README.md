# SQL Analysis

This folder contains the SQL scripts used throughout the E-Commerce Profitability Analysis project.

## Analysis Stages

The SQL analysis will be organized into the following stages:

1. **Data Exploration** – Understanding the structure, columns, and quality of the dataset.
2. **Data Cleaning** – Identifying and resolving missing values, duplicates, inconsistencies, and data quality issues.
3. **Sales Analysis** – Analyzing revenue, orders, sales volume, and sales trends.
4. **Profitability Analysis** – Analyzing profit, profit margins, and profitability by product, category, customer, and other dimensions.
5. **Customer Analysis** – Understanding customer purchasing behavior and identifying high-value customers.
6. **Product Analysis** – Evaluating product performance based on sales, revenue, and profitability.
7. **Trend Analysis** – Examining changes in sales and profitability over time.

## SQL Scripts

The scripts will be added as the analysis progresses.

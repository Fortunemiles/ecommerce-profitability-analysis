# Data

This folder contains the dataset used for the E-Commerce Profitability Analysis project.

## Dataset Description

The dataset contains transactional e-commerce data used to analyze sales performance, profitability, customer behavior, and product performance.

## Data Privacy

The dataset used in this project does not contain sensitive personal information.

## Data Preparation

The dataset will be inspected and prepared for analysis using SQL Server. Data preparation will include:

- Reviewing the structure and data types
- Checking for missing values
- Identifying duplicate records
- Checking for inconsistent or invalid values
- Validating relationships between relevant fields
- Preparing the data for analysis
